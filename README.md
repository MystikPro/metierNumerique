# Cartes mentales des métiers

Projet de cartographie des métiers sous forme de cartes mentales Mermaid (fichiers Markdown).

## Portée actuelle

Le projet couvre actuellement le domaine **numérique** dans le dossier `metierNumerique/`.

- `metierNumerique/carte_mental_metiers.md` : carte principale, vue d’ensemble des grandes sections.
- `metierNumerique/01_*.md` à `25_*.md` : cartes détaillées par grande section (développement, SEO/digital, data, cybersécurité, cloud, etc.).

## Évolution prévue

Le projet pourra être étendu à d’autres familles de métiers (industrie, santé, artisanat, services, etc.).

Cette extension demandera probablement une **réorganisation** de la structure, par exemple :

- un dossier par domaine (`numerique/`, `sante/`, etc.) ;
- une convention de nommage commune pour les cartes principales et les sections ;
- éventuellement un index global reliant les différents domaines.

## Utilisation

Les fichiers `.md` contiennent des blocs Mermaid `mindmap`. Ils peuvent être visualisés dans un éditeur compatible Mermaid (VS Code avec extension adaptée, outils Markdown/Mermaid, etc.).
